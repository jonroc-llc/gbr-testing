# How to Test — Get Books Reviewed

## What is GBR?

[getbooksreviewed.com](https://getbooksreviewed.com) is a subscription platform that helps authors get reviews for their books. Authors sign up, submit their books, and get matched with reviewers.

## What We Need Tested

### Core Flows
- **Sign up** — Create a new account (author and/or reviewer)
- **Book submission** — Submit a book for review
- **Reviewer matching** — Browse available books, claim a review
- **Dashboard** — Check your active reviews, submissions, account status
- **Payments** — Subscription checkout, plan changes, cancellation

### Things to Look For
- Broken pages or error messages
- Confusing UI or unclear instructions
- Slow loading or unresponsive buttons
- Mobile layout issues
- Anything that feels "off"

## How to Report

1. Go to the **Issues** tab on this repo
2. Use the **🐛 Bug Report** template
3. Include:
   - What you did (step by step)
   - What you expected
   - What actually happened
   - Screenshots or screen recordings (very helpful!)
   - Your browser and device

## Tips

- Test on both desktop and mobile if you can
- Try edge cases (long names, special characters, empty fields)
- If something seems wrong but you're not sure, report it anyway — we'd rather have a false alarm than miss a real bug
