# Get Books Reviewed — Testing & Feedback

This repo is for **bug reports, feature requests, and general feedback** for [getbooksreviewed.com](https://getbooksreviewed.com).

No code lives here — just issues and discussion.

## How to Submit a Bug

1. Go to the **Issues** tab above
2. Click **New Issue**
3. Select **🐛 Bug Report**
4. Fill out the template — be specific, include screenshots when possible
5. Submit!

## How to Request a Feature

1. Go to the **Issues** tab above
2. Click **New Issue**
3. Select **💡 Feature Request**
4. Describe what you'd like and why it matters

## What Happens Next

- Issues are triaged by the team (usually within 24 hours)
- You'll see status updates directly on your issue
- Check the **Project Board** for an overview of what's in progress
